⚠️ Antivirus False Positive Warning

Some antivirus programs on Windows (including Windows Defender or third-party antivirus software) may incorrectly detect this program as a virus.

This is known as a false positive detection, and it can happen because:

  • The software is new or not widely recognized yet
  • The executable is not digitally signed
  • The program uses low-level system or disk-related functions
  • Portable tools are sometimes misclassified by heuristic scanning

Important: This detection is NOT accurate. The software is safe to use.

Recommended Solution (Windows 10 / Windows 11)

If your antivirus blocks or flags the file, you can safely allow it by adding an exception:

Add Exclusion in Windows Security

  1. Open Windows Security
  2. Go to Virus & threat protection
  3. Click Manage settings
  4. Scroll to Exclusions
  5. Click Add or remove exclusions
  6. Select:
    • Add an exclusion → File or Folder
  7. Choose the folder where the portable program is located

If Windows Blocks the File

  1. Right-click the program file
  2. Select Properties
  3. If you see “This file came from another computer,” click Unblock
  4. Click Apply → OK

Final Note

This is a portable program , meaning no installation is required. Simply extract and run the program directly.

For safety, always download this software from the official source.
